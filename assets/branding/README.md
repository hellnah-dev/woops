# Branding assets

Put your logo here as **`logo.png`**:

- Square, transparent background, at least **512×512 px** (1024×1024 recommended).
- It is shown automatically on the splash, welcome, sign-in and discover screens
  via the `AppLogo` widget (`lib/core/widgets/app_logo.dart`). Until the file
  exists, a placeholder box of the same size is shown.

For the **app icon** (home screen), see "App icon" in the main README.
